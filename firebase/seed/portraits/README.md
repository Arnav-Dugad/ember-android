# Demo profile portraits

These 240 images (p01.jpg to p240.jpg) are AI-generated (Figma AI image generation) and depict fictional people who do not exist.
They were made only for Ember's demo/seed profiles and are not photos of real people; see manifest.json for per-image metadata
(gender, apparent age, setting, vibe and city) and ../shared/people.json for the matching demo profile written for each image.
